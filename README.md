mend — one patch tool for every AI edit format: it applies unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool-call edits to a tree of files, to one written specification, finding the lines an edit names even when the model drifted their whitespace or indentation, and changing every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
